## From course project to production

IBO & CO began as my project for the web programming course: a website for a real pharmacy in Sarajevo with two locations. It turned out good enough that the pharmacy put it into production, and it is now their official website and web shop.

## What it does

- A product catalogue with categories and a shop
- User registration and login [provjeri: profile, order history]
- Information about both pharmacy locations, reviews and contact [provjeri]
- [provjeri: an admin side for managing products and orders]

## How it is built

The frontend is a single-page app in HTML, CSS, JavaScript and jQuery with Bootstrap. It talks to a REST API in PHP on the FlightPHP framework, organized in layers - routes, services and data access objects - on a MySQL database.

## What came next

Version 1 works and serves real customers, but it was written while I was learning. In 2026 I rebuilt it from scratch as [IBO & CO 2.0](/work/ibo-co-2/), in TypeScript end to end, keeping every feature and the pharmacy's visual identity.
